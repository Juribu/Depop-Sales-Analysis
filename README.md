# Depop Market Analysis
- Analyzed five years of sales, pricing, product, and buyer data from a Depop resale business.
- Used Python with Pandas and NumPy to clean and standardize 14,424 records from manual sales logs and quarterly Depop exports.
- Feature-engineered profit margin, return on investment, markup, boosting status, and selling-time variables.
- Conducted exploratory data analysis using Matplotlib and Seaborn to identify sales, pricing, and geographic trends.
- Built regression models and performed hypothesis testing with Statsmodels.
- Found that higher sourcing costs were linked to lower returns and paid boosting did not significantly reduce selling time.
- Identified differences in product preferences and prices across states.
